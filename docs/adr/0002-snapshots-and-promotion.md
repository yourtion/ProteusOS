# 以不可变快照和原子晋升隔离行为变化

多个任务并发执行时，直接改写共享 Skill 或策略会使来源、评估与恢复失去确定性。每个 Run 因此固定一个包含完整版本依赖的 GenomeSnapshot；晋升通过目标 Organism 的快照指针与 revision 条件更新，只影响后续 Run。

考虑过运行中热更新和全局停止后的代际切换；前者难以追溯，后者让长任务阻塞更新。采用快照隔离需保留旧版本并处理并发候选的重评，但可使运行与学习同时推进。回滚也产生新的采用记录和 revision，不撤销既有外部副作用。

active 是个体与快照的关系，不写成不可变版本上的可变状态。详见[领域模型](../domain-model.md)与[进化协议](../evolution.md)。
