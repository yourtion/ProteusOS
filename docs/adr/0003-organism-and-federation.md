# 以个体为学习归属，通过联邦继承共享成果

一个 Organism 拥有持续身份、独立经验和默认行为选择权，其多个 Process 可以并发完成任务。团队协作采用具有明确归属的产物与证据交换，通过 import/fork/inherit 形成各自的候选与采用记录。

考虑过所有成员共享可写 Memory/Policy；该方案会混合个人偏好、权限和评价目标。独立谱系增加导入校验与本地评估成本，但允许个人拒绝或调整团队成果，并保留行为变化的来源。实现保留 owner/scope/lineage/provenance；本地继承见 ADR 0009，签名来源信任与 HTTP registry 见 ADR 0010。真正共进化未实现。

发布不等于激活，公开产物也不自动公开其来源经历。详见[进化与协作](../evolution.md)。
