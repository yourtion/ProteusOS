# 基质与可进化行为分离

ProteusOS 将身份、授权、版本完整性和晋升协议作为稳定基质，将图调度置于 Runtime，将策略、Skill、模型与代码作为上层可版本化行为。这样增加学习能力或更换执行器时，不会同时改写系统约束。

考虑过直接以现有 Agent harness 或插件宿主作为核心；本设计选择自有领域合同，ACP、其他执行协议及插件宿主均可通过 Adapter 接入。代价是需要自行实现运行一致性与恢复；收益是持久身份、经验和变化规则不依赖某个外部会话模型。

Kernel 的常规软件升级仍然允许，但不属于运行时自主演化。详见[总体架构](../architecture.md)。
