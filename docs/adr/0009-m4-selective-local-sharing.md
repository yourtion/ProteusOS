# M4：独立个体、本地发布与选择性继承

M4 采用单实例多 Organism 与离线分享包交换。Runtime、Evolution 和 CLI 绑定明确个体与操作者；经验窗口、作业、预算、候选、评估和晋升按个体隔离。实验入口同时绑定任务归属、配额、输出目录与报告证据，同名实验不会跨个体累计额度或复用记录。旧实例的默认个体实验额度迁移后仍有效。团队身份与 read/publish/manage 授权独立记录，拥有身份或知道版本 ID 不产生操作权限。操作者仍是本地受信的身份声明者；本轮不建立网络认证、远程 registry 或多租户服务。

内容摘要不能合并不同归属的授权对象。ArtifactVersion 固定 scope，版本去重以 artifact/content/scope 为键；新快照摘要包含槽位内容、Artifact 身份、scope、Lineage 与完整依赖闭包，固定 public seed 仍能跨实例重复，而 fork 和不同归属的相同内容保持独立。迁移保留历史版本 ID、快照、事件与 active 指针；精确 bindings 复用历史快照，不原地重写历史摘要。

Federation 封装 publication/import/fork/inherit。分享包采用严格字段白名单：精确根版本、完整依赖闭包、内容摘要、允许公开的来源引用，以及操作者明确选定的数字汇总证据。证据须来自当前个体的 eligible 评估，且发布内容与依赖均在该评估候选闭包中，不能给其他版本附上无关的通过结论。不会自动携带 Task、Experience、原始运行、私有提示或凭据。私有父版本只保留在发布方本地的谱系中，包中标明未披露数量；public 包含私有或团队依赖、团队包带其他 scope 依赖均拒绝。需要扩大共享范围的依赖必须被操作者逐项明确选中 fork，不能依靠 public 标签自动公开。

外部包严格检查总摘要、逐版本摘要、重复 ID、依赖闭包与依赖环。导入创建接收方本地谱系与版本，parents 引用精确来源版本；缺少本地内容的外部父版本保存为明确的 provenance 引用，不伪造可执行 blob。原始分享包保存在内容存储中以复核外部主张。public 内容可由任何本地授权操作者导入；team 内容需要接收方本地已登记的团队和读取授权，包本身不能赋予这些权限。

发布、导入和 fork 均不改变 active。inherit 只选择本地导入版本，固定本地基准 revision、裁判与预注册验证计划，构造独立候选；团队的 eligible 证据仅为外部主张，不能充当个人晋升证据。不同个体各自评估、批准、CAS 晋升或拒绝；拒绝不撤销已经发生的行为。裁判变化仍必须单独验收，导入不能换裁判自我放行。导入的能力代码及其派生版本要求真实隔离后端执行；测试使用受信 fixture 后端验证合同，未将模拟后端当作真实隔离结论。Docker 后端不在本次范围内。

验收故事证明：两个不同归属的个体导入同一团队版本，A 经自己的冻结任务比较后采用并修复新任务，B 拒绝且默认指针不变，私有任务 sentinel 不出现在分享包。集成测试覆盖共库个体隔离、团队授权、篡改和非法依赖拒绝、来源与 fork 谱系、拒绝后的晋升边界、导入代码隔离合同；CLI 故事覆盖真实命令入口。真实模型收益、网络联邦和持续共进化仍需独立验证。

后续签名来源认证、撤权与 HTTP registry 已在 [ADR 0010](./0010-signed-sharing-and-registry.md)实现；本文保留 M4 本地交换的决策范围，当前命令见 [共享使用说明](../sharing-registry.md)。
