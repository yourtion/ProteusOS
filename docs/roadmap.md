## 3. 自举验收故事

ChangedFileSummary 的验收流程由 `tests/acceptance/bootstrap-story.test.ts` 固化：

1. 缺少能力的任务创建固定快照的等待 Run；到期或显式接替后结案。
2. 在独立工作区委托构建，固定测试通过后记录产出摘要。
3. 采集不可变能力版本，构造候选并固定输入、裁判、预算与回归计划。
4. 独立评估新能力及既有能力回归；健康基线失败记 inconclusive。
5. 操作者批准 CAS 晋升；冲突候选返回 stale，须重建与重评。
6. 显式 supersede 创建使用新快照的接替 Run，完成原任务。
7. 回滚到历史采用快照，revision 继续增长；保留已发生的结果和证据。

裁判变化先作为独立候选评估与晋升，再评估能力候选。

## 4. 持续验收的失败场景

| 场景 | 预期行为 |
| --- | --- |
| 候选失败、输出非法或依赖缺失 | 保留证据，禁止晋升 |
| 同 revision 并发晋升 | 一个成功，另一个 stale |
| 提交成功但响应丢失 | operationId 读回原结果，不重复增加 revision |
| 外部调用结果未知 | 保留 unknown，不假定未执行并自动重发 |
| 在途 Run 遇到默认版本变化 | 原 Run 和恢复仍用原快照 |
| 权限撤销 | 阻止新调用和派发；已发生的结果不被抹去 |
| 未发送调用取消或撤权 | 提交取消终态，释放未发送额度 |
| 迟到响应 | 追加证据，不覆盖已确认终态或派发 worker |
| 更换裁判或固定验证内容漂移 | 拒绝自我放行与借用旧证据 |
| 冻结成员/输入 blob 缺失 | 明确不可回放，不填充替代内容 |
| 共享内容带私有依赖 | 发布/导入拒绝 |
| 来源公钥撤信或 registry 凭据撤销 | 拒绝相关新动作，保留历史证明与本地采用记录 |

实现边界见 [运行时合同](./runtime.md) 与 [进化流程](./evolution.md)，标准检查见 [仓库设计](./repository.md)。

## 5. 后续迭代方向（2026-10-10 规划）

结合原始架构与 [DSPy 论文](https://arxiv.org/pdf/2310.03714)，下一主线为**先补可替换决策层，再验证经验驱动适应**。Jev 是在线 DecisionProvider 的一种实现；DSPy 方法用于离线参数优化。以下是规划，尚未实现；方向核对见 [架构差距](./architecture-gaps.md)，模块落点、预算、效果门与停止条件见 [后续迭代规划](./iteration-plan.md)。一手资料分别见 [Jev 研究](./research/jev-decision-plane.md) 与 [论文笔记](./research/dspy-paper.md)。

| 顺序 | 目标 | 预计投入 | 进入下一阶段的依据 |
| --- | --- | --- | --- |
| P0：架构与证据基线 | 核对原始方向、现有 v1、Jev 服务/SDK；冻结新的决策层协议和预算 | 1 周 | 设计、工程与真实收益分开；原 v1 门槛不变 |
| M5：可替换决策层 | Jev choice、概率证据、弃权/校准、规则/LLM/Jev 比较；按需扩展 binary/score/级联 | 核心 2–3 周；扩展另估 1–2 周 | 真实接入可验证、约束与恢复成立；Provider 胜出与替换能力分开判断 |
| M6：经验适应与编译 | Prediction/Outcome、许可 replay、自我事实投影、通用学习合同；策略有界搜索与独立比较 | 4 周 | 同一个体因许可经历在新 family 上获得可验证改善；不足不晋升 |
| M7：有限多模块流程 | 类型化模块数据传递；按需要增加 Memory 检索或 Skill 蒸馏；端到端效果对照 | 2–3 周，M6 收益后 | 新增模块有独立内容合同，并带来可复现收益 |
| M8：团队产物本地继承 | 复用签名包/registry；接收方本地适配、重新评估与选择采用 | 1–2 周，M7 收益后 | 两个个体独立采用/拒绝，私有原文不泄露；不据此宣称共进化 |

近期建议投入 P0 + M5 的 Jev choice/概率证据/校准，并交付下节的 U0/U1 Web。决策工作估 3–4 周，应用 Interface/基础 Web 另估 2–3 周；单开发者顺序执行约 5–7 周，不含独立验证资料和服务等待。M5 第二类决策/级联按需求另估，M6–M8 按证据排队。Jev 保留本地模型替换路径；离线编译的 DSPy worker 是可选对照，不替代在线决策层。

保留正式 ValidationSet 的单候选绑定、一次领用与 family 防回流；新增搜索选择集用于开发侧多参数比较。成本必须覆盖编译、正式评价和线上运行，未知金额不按零计。质量/成本门须在搜索前固定，不修改现有 v1 的冻结门槛。

真实数据保留、删除和训练用途治理在接入私有经验前完成。模型微调、自动晋升、动态图、学习式世界/自我模型、元可塑性、大规模联邦与真正共进化继续后置；最小预测/观测和事实自我投影进入 M6。生产 registry 部署由真实协作需求触发。
