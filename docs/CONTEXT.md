# ProteusOS 领域词汇

ProteusOS 承载长期存在、通过经验改进的智能个体。本词汇表区分身份、执行、可继承结构与变化证据；协议、存储和代码组织见其他设计文档。

## 身份与执行

**Substrate（基质）**：使个体能够持续存在、执行任务和受控变化的共同规则与基础能力。
_Avoid_：大脑、超级 Agent

**Organism（个体）**：具有持续身份、独立经验归属和行为版本选择权的智能主体；其身份延续不依赖某个模型或执行进程。
_Avoid_：模型、会话、进程

**Principal（授权主体）**：能够拥有资源或授予权限的用户、个体或团队身份。
_Avoid_：将 owner 与执行者视为同一概念

**Task（任务）**：具有目标、约束和验收条件的一份工作请求。
_Avoid_：Run、执行器会话

**Run（运行）**：某个 Organism 对一个 Task 的一次完整执行，具有确定的行为版本集合和运行结果。
_Avoid_：Process、会话

**Process（执行单元）**：Run 内具有局部职责、资源配额和生命周期的工作单元，可以与其他执行单元并发。
_Avoid_：独立个体、操作系统 PID

**Attempt（尝试）**：Process 的一次实际执行；重试产生新 Attempt，并保留先前尝试的记录。
_Avoid_：用重试覆盖原执行

**Environment（环境）**：一次运行所处的外部条件，包括工作对象、可用能力和影响结果的依赖条件。

**Budget（预算）**：对 Run 或 Organism 允许消耗的资源上限及其记账关系，涵盖预留、消耗、释放与未知成本的保留语义。
_Avoid_：把未知成本记为零、以执行器自报费用代替账本

## 行为与继承

**Artifact（产物）**：具有稳定标识和明确用途、能够被引用与管理的内容对象。
_Avoid_：所有产物都天然可执行或可继承

**ArtifactVersion（产物版本）**：某个 Artifact 的不可变内容及其来源记录；对内容的修改产生新版本。
_Avoid_：可被原地更新的版本

**Lineage（谱系）**：具有明确归属的版本演变家族；版本间的继承和重组关系形成可追溯的有向无环图。
_Avoid_：单一递增版本号、Organism 身份

**GenomeSnapshot（行为快照）**：某个个体可使用的可继承产物版本及其依赖的完整、不可变组合。
_Avoid_：latest 集合、运行中的工作记忆

**Genotype（可继承结构）**：能够在不同运行间保留、选择和继承的行为结构的统称；GenomeSnapshot 是其一次具体组合。

**Phenotype（运行表现）**：个体在特定环境中呈现的行为和临时状态，由行为快照、输入与经历共同形成。
_Avoid_：可直接复制给下一代的全部状态

**Seed（种子）**：系统首次安装时导入的初始规则与可继承产物集合，经版本化安装后构成首个 GenomeSnapshot。
_Avoid_：把仓库中持续变化的源文件当作已固定的种子版本

**Policy（策略）**：在约束条件下选择行为的可版本化规则。
_Avoid_：某一模型、权限授予

**Decision（决策）**：针对明确问题与候选空间的一次结构化选择、排序或判断。
_Avoid_：授权、开放式内容生成

**Capability（能力）**：执行某类操作所需的声明与契约；拥有能力实现不代表获得使用该能力的权限。

## 经验与变化

**Experience（经验）**：将一次运行的上下文、行为、预测、观测和结果关联起来的可追溯经历。
_Avoid_：未经来源关联的摘要、正确答案

**Outcome（结果）**：依据任务验收条件对实际发生情况的记录；可以包含未知或部分完成。
_Avoid_：执行器自报成功

**Evidence（证据）**：支持某项评估或变化主张、带有来源与适用条件的观测材料。
_Avoid_：主张本身、无条件事实

**Credit（贡献归因）**：关于某个版本或行为对结果影响的、有方法和不确定性说明的归因主张。
_Avoid_：参与即功劳、相关性即因果

**Consolidation（巩固）**：从多次经验中形成可复用结构的过程，其输出可以成为候选产物。
_Avoid_：直接覆盖当前行为

**Candidate（候选变更）**：针对目标行为组合提出的一组版本替换及其改进假设。
_Avoid_：已批准版本、已生效能力

**Evaluation（评估）**：在固定条件和标准下比较候选与基线的记录。
_Avoid_：晋升授权

**Promotion（晋升）**：根据证据与授权，将候选组合选为指定个体后续运行默认行为的决定。
_Avoid_：修改旧版本、所有个体同步升级

**Rollback（回滚）**：将后续运行的默认行为恢复到先前可用组合的决定。
_Avoid_：撤销已经发生的外部行为

**Plasticity（可塑性）**：某类状态允许变化的范围、节奏和准入条件。
_Avoid_：无限制自修改

## 协作与治理

**Scope（作用域）**：资源或变化适用的身份范围；可见性、所有权和晋升权限是不同关系。
_Avoid_：仅凭 public/team 标签推导权限

**Inheritance（继承）**：将其他谱系的特定版本纳入自身候选组合的行为。
_Avoid_：自动跟随远端最新版本

**Federation（联邦协作）**：独立个体或团队通过有选择的产物与证据交换共同改进，同时保留各自的接纳权。
_Avoid_：共享可写大脑、默认共享全部经验

**Co-evolution（共进化）**：多个独立主体的行为变化相互影响后续学习与选择的过程。
_Avoid_：并发任务、多角色协作
