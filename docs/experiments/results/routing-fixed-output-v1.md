# 输出上限 256 / 512：真实固定对照结案

2026-10-28。**提高到 512 改善了本轮任务成功率，但尚未达到预定的 95% 合法 JSON 门槛。** 本段 120/120 完成、计量与结束证据完整、清理重开和解包回放一致，没有新增未知。

从干净提交 `f9905b237bf5a3029301090ba114b468585c797a` 运行 [O2-R1 协议](../fixed-output-v1.md)。20 个另外的开发任务、10 个模板 family ×2 资料变体、每条件 3 repeats。两条件均为旧 v1 布局、零示例、同一 GLM-5.3-Flash 服务、同一裁判与受约束 worker；唯一改变模型请求的因素是 max_tokens=256/512。资料为开发方可见，不宣称独立保管或泛化收益。

## 完整结果

| 输出上限 | 实际验收成功 | 非法 JSON / 达上限失败 | 关键任务失败 | 已知输入 tokens | 已知输出 tokens | p95 Run 延迟 |
| --- | --- | --- | --- | --- | --- | --- |
| 256 | 40/60，66.67% | 20/60 | 2/12 | 18,876 | 12,779 | 9.155 s |
| 512 | 56/60，93.33% | 4/60 | 0/12 | 18,876 | 15,841 | 14.037 s |

两个条件均完成全部 60 单元。有效选择未观察到误派；失败均为非法输出，服务结束原因 max_tokens。不能将有效选择的正确性替代整体可靠性。

同任务/同 repeat 的 60 个配对中：两者成功 40、仅 512 成功 16、仅 256 成功 0、两者失败 4。成功率净增 **26.67 个百分点**，达上限失败减少 **80%**。这是当前开发资料上的描述性结果，重复与资料变体不当成独立 family，不提供独立统计收益结论。

输入 token 总数完全相同；输出增加 3,062 tokens，约 **23.96%**。中位 Run 延迟 256 为 6.844 s，512 为 7.021 s；p95 增加 4.882 s。费用/币种未知，不能把 token 合计直接换算为金额。

## 判定与限制

`dispatchComplete=true`、`engineering=passed`（只判断当前阶段）、`unknownUsageCalls=0`。新协议的两次 5xx 容错没有被使用，全部 120 次取得实际响应和用量。

512 的成功率 ≥90%、关键任务全过、改善 ≥5 个百分点，但其合法 JSON 率 **93.33% <95%**，因此 `confirmationPassed=false`、`descriptiveQualityGate=false`。保留失败，不放宽门槛、不补考。独立收益仍 inconclusive，正式 Evaluation / adoption 均 not_run，activeGenome 未改变。

原 [八条件矩阵](./routing-diagnostic-matrix-v1.md)因服务 500 停止、selected=null 的结果保持原样。本轮是另注册的固定额度对照，不把它写成合格矩阵候选或示例/编译改进；原 O2-03 / O2-04 的准入条件未达到，不扩展 M6b/M6c。
