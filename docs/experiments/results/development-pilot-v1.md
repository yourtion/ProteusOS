# 首个真实开发试点结果

2026-10-29。按 [试点协议](../development-pilot-v1.md)，完成 ProteusOS 仓库内一个真实缺陷的“固定复现 → 真实编码 Agent → 独立验收 → 审查修复”流程。功能闭环通过，成本/完整轨迹与相对收益尚未证明。

## 问题与结果

JSON Schema 子集校验器将原型继承的字段当作输出字段：空对象满足 `constructor` / `toString` 等必填项，可选继承字段又可能被误报类型错误。公开 `evaluateHybridOutput` 入口同样受影响。父任务先发现、定位问题并固定测试，然后交给模型实现修改；本轮不测独立问题发现或诊断能力。

| 阶段 | 实际结果 |
| --- | --- |
| 修复前 | 12 项固定检查中 8 项失败、4 项健康回归通过；公开验收入口回归失败 |
| 真实第一轮 | 125.995 秒，1 个 Attempt，运行失败；权限回调误读工具名称，3 次目标文件写入被拒绝 |
| 提案审查 | 三次 Write 中的源码提案摘要相同；从轨迹原样取出后 12/12 通过，审查后应用到仓库 |
| 接入修复 | 兼容标准 `toolCall.name`，保留旧元数据回退；拒绝名称冲突、输入写入和越界路径，18 项定向检查通过 |
| 真实第二轮 | 用户追加授权后，从相同旧源码开始；56.487 秒，1 个 Attempt，自动写入并独立验收 12/12 通过 |
| 仓库验证 | 静态检查通过；74 个测试文件，473 passed /5 skipped。初次有 7 项因 loopback 权限/超时失败，放开本机监听后对应 3 文件/9 项全部通过 |

首轮提出的修复仅新增自身字段检查，并替换两处 `in` 判断；提交 `d82402d`。主仓库源码与原始模型提案逐字节一致，SHA-256 `b916225f8d484e7c0e427b744001f45c56c623bd3c2f528884e89a5d8cd11ba1`。第二轮将相同逻辑提取为模块级辅助函数，单独保留其 [补丁](./development-pilot-v1/attempt-2.patch)，没有再次替换已采用的修复。

本轮执行入口、固定宿主验收及权限兼容测试已提交 `8d22656`。两个临时实例的 active 都保持种子快照，无正式 Evaluation/Promotion 采用。`purpose=evaluation` 的运行用途不等于正式收益评估通过。

## 实际使用中发现的限制

1. **权限合同需要真实兼容测试。** 首轮确实使用真实模型，但原调用被记为失败，不能将后来人工提取的有效提案改记为首轮自动成功。
2. **流式轨迹应先聚合再持久化。** 第二轮 `traceStatus=partial`，256 事件缓冲丢弃 132 个事件；验收结果、目标源码与摘要保留，不能宣称全部执行过程已完整保存。
3. **完整用量仍待接通。** ACP 当前没有项目要求的完整模型调用及 token/金额合同，本轮这些字段为 null。不能将“一个 Attempt”当作一次模型调用，也不能把 56.487 秒当作整个试点投入或效率优势。
4. **当前交付是单模块试点入口。** 源码只含标准库，测试由宿主固定执行；接入普通项目还需要项目输入清单、依赖/构建配置、多个产物文件与相应验收合同。真实收益比较和更广泛任务验证仍为 inconclusive。

下一切片建议先处理轨迹聚合、执行进度和用量证据，再用 10–20 个真实开发任务比较直接使用编码 Agent 与 ProteusOS 编排。先固定每项任务的验收与预算，记录人工介入和失败，不从当前一个样本推导普遍成功率。
